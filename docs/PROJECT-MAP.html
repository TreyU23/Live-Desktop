Live Desktop, explained from the outside in

Live Desktop is a control panel for one Windows PC that opens in a web browser tab. It shows how the computer is doing, lets you flip a few switches, holds an AI assistant you can chat with, and gathers your calendar, phone and music in one place. This map shows what the project is made of and exactly what every part of the dashboard does.

  • 7 pages
  • 9 cards on the Overview page
  • 3 building blocks: Screen, Brain, Hands
  • Runs only on this PC
  • Nothing changes your PC without your approval

1

The big picture: three parts that pass notes

Think of a restaurant. The Screen is the dining room you see. The Brain is the kitchen that decides what is allowed and remembers every order. The Hands are the one staff member trusted to touch the equipment, which here is Windows itself.

Part 1 · the Screen

What you see

The web page with its side menu and seven pages. It draws things and collects your clicks. It decides nothing about safety and stores only looks and layout choices (theme, accent color, profile names and photos, your music link).

Part 2 · the Brain

What decides

A program running quietly in the background. It keeps your conversations, memories and approvals, talks to OpenAI and iCloud, checks every action against a fixed allowed list, and makes sure only this PC can talk to it.

Part 3 · the Hands

What acts

Four small Windows programs: the launcher that starts everything, a host that serves the page, the bridge that reads from and changes Windows, and a credential helper that locks saved passwords to your Windows account.

2

Always on screen, whichever page you are on

Side menu (left edge)

  • Live Desktop name shows the PC's name and whether the Brain is reachable.
  • Page list in four groups: Desktop, Assistant, Media, Live Desktop. A number badge on Approvals counts requests waiting for you.
  • Profile button at the bottom opens the profile picker.
  • On a phone-sized window the side menu folds away behind a menu button at the top.

Top-right of every page

  • Status pill: Local mode · stored on this PC when things work, Backend offline when the Brain cannot be reached.
  • Restart button restarts the Screen and the Brain, then reloads the page by itself within a minute.
  • Power button asks for confirmation, then stops Live Desktop. It never shuts down Windows. To start again you run start.cmd.

Profile picker

Profiles are separate drawers for different people or purposes on the same PC. Each has its own conversations, memories, approvals, saved keys, theme and music link.

  • Switch profile, rename it, change its photo, or create a new one.
  • Delete a profile and all of its data after a confirmation. The first profile cannot be deleted.
  • Profiles organize data. They are not passwords and do not lock anyone out.

Messages the dashboard gives you

  • Pop-up notes at the edge confirm what just happened or explain an error, then fade after about four seconds.
  • Per-card status: each card says when it is still waiting for data, shows the last good data with a time if a refresh failed, and offers a Retry button.
  • Refresh banner at the top lists anything that could not refresh, with one button per item.

Overview

1Performance
Three dials: how busy the processor is, how much memory is in use, how full the drive is. Each dial has a small trend line of recent readings. Dial color means: under 75% 75 to 89% 90% and up. A dash means no reading, never a guessed number. The storage dial covers the drive Live Desktop is installed on, not every drive.
2This PC
Computer name and Windows type, whether the network is connected, current download and upload speed, how fast the disk is reading and writing, and battery percent if the PC has a battery. A link opens System Info.
3Controls
Two real switches: Wi-Fi and Bluetooth. Clicking one asks to turn it on or off; nothing changes until you allow it. Four shortcuts: Focus, Night light, Mic privacy and Battery saver. These only open the matching Windows Settings page, and the section says so. A banner above the page sections shows how many requests are waiting for your decision.
4Calendar
Your iCloud events for one day, read-only. Arrows move a day back or forward, Today jumps back, the round arrow refreshes. It shows the first three events, all-day ones first, and Show all lists the rest. “Now” marks an event happening right now. If iCloud is not connected, the card links to Settings. On a day with no events it offers to open the Windows Calendar app, and tries iCloud on the web if that fails.
5Now Playing
Song title, artist, album, cover art and progress for whatever is playing through Windows, with shuffle, previous, play or pause, next and mute. If nothing is playing it offers to open your music service.
6Ask Live Desktop
A one-line box to message the assistant. Three example questions sit underneath, and clicking one only fills the box. Pressing send takes you to Conversations to read the reply.
7Phone
What Microsoft Phone Link reports about your paired phone: its name, connection status, system and model, battery, and last sync time. Buttons refresh it, copy the phone's name, and open the Phone Link app. It can show that notifications exist, but never their contents.
8Connections
Four status lights: the Brain (Local API), iCloud, the OpenAI key, and Music.
9Recent activity
A short table of well-known apps Windows reports as running or installed. It shows four, with Show all for the rest.
2

System Info

DesktopTwo tabs.
Live tab
Bars for processor, memory and storage, then a table of network and disk speeds with a trend line for the last 15 minutes. Beside them: the device (name, processor, memory, system type, and IDs hidden until Show IDs) and Windows (edition, version, build, install date). Copy specifications copies the details.
Specifications tab
Device: name, manufacturer, model, processor, installed memory, graphics, system type, plus Device ID and Product ID, which stay hidden until you press Show IDs. Windows: edition, version, install date, build and architecture. Live status: network, battery, whether the Brain and the OpenAI key are ready, the Java version, and the time of the last reading.
Good to know
Everything here is read locally with normal user rights. No administrator access is requested and the Windows product key is never read.
3

Conversations

AssistantChat with the AI assistant.
Thread list
Every saved conversation with its message count and time. New starts a new one. On a phone-sized window it becomes a drop-down.
Chat panel
Your messages and the assistant's replies. Enter sends, Shift+Enter adds a new line. If sending fails, your draft stays in the box. A warning appears when no OpenAI key is saved.
What the assistant can do alone
List and read text files inside the Live Desktop folder (never your saved data or secret settings files), look up memories you saved, and read live dashboard information such as system status, apps, phone, calendar and music.
What it must ask for
Writing a file in that folder, opening a website in your browser, and saving a new memory. Each of these becomes an approval request.
Approval window
If a request appears while you are on this page, a window opens with Allow, Don't Allow and Decide later. A Review requests button reopens it. The same requests are listed on the Approvals page.
Where it goes
Conversation history is saved on this PC. Your message, recent messages from the same chat, and any relevant dashboard details are sent to OpenAI to produce the reply.
4

Approvals

AssistantThe checkpoint for anything that changes the PC.
Pending and History
Two tabs. Pending lists requests waiting for you, with a count. History lists everything already decided, each marked completed, failed or not allowed.
Details
The arrow at the start of a row opens it: what it will do, the exact target (a file, a web address, a control), what future requests the approval would also cover, the full content if it writes something, the result afterwards, and when it was requested.
Buttons
Allow runs it now and remembers the permission. Don't Allow cancels it and nothing happens.
5

Memories

AssistantNotes the assistant may use later.
Memory list
Every saved note for this profile in a table, with a search box and a Delete button on each one that asks before deleting.
Add a memory
Add memory opens a small window. Type up to 2,000 characters, pick a category (preference, project, fact or instruction) and save. Notes you add here save straight away. Notes the assistant wants to add go through approval first.
6

Music

MediaPlayer and provider choice.
Player
The same song information and buttons as Now Playing, plus a switch between Apple Music and Spotify and a button to open the service outside Live Desktop.
Web player
Apple Music's or Spotify's own player for the playlist, album or song link you saved in Settings. You sign in inside that player. Once you have visited this page, the player keeps running while you use other pages.
How the buttons work
Live Desktop does not log in to your music account. It reads the current song from Windows and sends play, pause and skip through Windows, so a track has to be started once before the buttons respond.

Settings

Live DesktopConnect services and choose the look.
Profile
Shows the current profile and opens the profile picker.
Appearance
Theme: light, dark, or System to follow Windows. Accent: Neutral (black and white), Blue, Green, Orange or Red. Each choice is a complete, tested color set, so text stays readable in both themes.
Assistant
Save, replace or remove the OpenAI key that powers the assistant. Once saved it is never shown again. A link opens Approvals.
Connections
iCloud Calendar: connect with your Apple email and an app-specific password, or disconnect and erase the saved login. Music service: choose Apple Music or Spotify, paste a share link, refresh status, open the full player, or remove the link. Phone Link: open the Phone Link app.
Live Desktop services
Restart or shut down Live Desktop itself. Windows keeps running either way.

The approval rule

Looking is free. Changing needs a yes. The first time something would change your PC, it waits for you. After you allow it once, the same kind of request runs without asking again in that profile.

Kind of actionWhere it comes fromWhat one “Allow” also covers later
Turn Wi-Fi or Bluetooth on or offControls cardAny later on or off change of that same control
Open a Windows page or app
One of nine fixed destinations: six Settings pages, Phone Link, Windows Calendar, Spotify		Controls shortcuts, Phone card, Calendar card, MusicOpening that exact destination again
Open a website in your browserThe assistant, iCloud Calendar on the web, Apple MusicOpening that exact web address again
Write a file in the Live Desktop folderThe assistantAny later write to that same file, with any content
Save a memoryThe assistantAny later memory in the same category

No approval needed: reading anything, music buttons (play, pause, skip, shuffle, mute), adding or deleting your own memories, and restarting or shutting down Live Desktop (shutdown asks for a simple confirmation).

How fresh the data is

The Screen asks the Brain for new data on a timer. It pauses while the browser tab is hidden and catches up when you come back. A request that takes longer than 12 seconds is given up and reported on its card.

WhatChecked everyShown on
Current song5 secondsNow Playing, Music
Phone status10 secondsPhone card
Processor, memory, storage, network, battery, controls15 secondsPerformance, This PC, Controls, System Info
Is the Brain reachable, is Live Desktop running30 secondsStatus pill, Connections
Apps, approvals, memories, conversation list, key status60 secondsRecent activity, Approvals, Memories, Conversations, Settings
Calendar events4 minutesCalendar card

Trend lines keep the latest 60 readings, about 15 minutes, and start empty each time the page loads. Anything you change yourself refreshes straight away. Turning Wi-Fi or Bluetooth on or off outside Live Desktop can take up to about a minute to show.

6

What stays on the PC and what leaves it

Stays on this PC

  • Conversations, memories and the approval history, in the data/ folder, one drawer per profile.
  • Your OpenAI key and iCloud login, scrambled by Windows so only your Windows account can unlock them.
  • Theme, accent color, profile names and photos, and your music link, kept by the browser.
  • All PC readings. System details are shown, not saved.

Goes out to the internet

  • OpenAI: what you type to the assistant, recent messages from that chat, and only the dashboard details that relate to your question. Hardware IDs, maker, model and processor name are left out.
  • Apple iCloud: your calendar login, to fetch events.
  • Apple Music or Spotify: whatever their own web player sends once it loads.

How the door is kept shut

The Brain only answers requests that come from this same computer. Each time it starts it makes a new secret pass, and every request must carry it, so another website open in your browser or another device on your Wi-Fi cannot give it orders. The Hands accept instructions only from the Brain, over a private channel, and only from a fixed list of operations. There is no “run any command” option anywhere.

Folder map

What you find when you open the project folder. Dots show which of the three parts a folder belongs to.

frontend/
The Screen. Seven page files in src/views/, the shared pieces in src/components/, the color themes in src/themes/ (built from themes/ with the Astryx tools), and src/App.jsx, which connects every button to the Brain.
backend/
The Brain. One file lists every request it accepts, and separate files handle approvals, memories, PC readings, calendar, music, saved keys, profiles and the assistant.
native/
The Hands. Four subfolders: launcher/, host/, windows-bridge/ and credentials/.
data/
Your saved information. Private, never uploaded to GitHub. Other profiles live in data/profiles/.
start.cmd
The file you double-click to start Live Desktop.
scripts/
Helper scripts for people building the project: build, run, test, measure speed, package a release.
docs/
Written guides: the working guide, release notes, test records, and what the system and control features can and cannot do.
README.md, PRODUCT.md, DESIGN.md
How to install and run it, what the product promises, and the rules for how it should look.
dist/
Finished download packages and release notes.
.tools/
A private copy of Java 21, the engine the Brain runs on, so nothing extra has to be installed.
.github/
Instructions GitHub follows to publish a release package.
build/, native/build/, backend/target/
Machine-made output from building the project. Safe to ignore.
8

What it will not do

  • It does not shut down or restart Windows. The power buttons only affect Live Desktop.
  • It does not switch Focus, Night light, Mic privacy or Battery saver itself. It opens the Windows page where you can.
  • It cannot add or edit calendar events. The calendar is read-only.
  • It does not read your phone's messages or the text of notifications.
  • It has no voice input.
  • The assistant cannot run programs or commands, and cannot read files outside the Live Desktop folder.
  • It never invents a reading. When Windows gives no number, the dashboard says unavailable.
  • It works on Windows 10 and 11 only, and is not reachable from other devices.

Word list

Frontend
The Screen. The part of a program you see.
Backend
The Brain. The part that works out of sight.
Bridge
The small program that passes requests from the Brain to Windows.
localhost
A web address that means “this same computer”. localhost:4173 is the dashboard's address.
API key
A long password from OpenAI that lets the assistant work. OpenAI bills its use separately.
App-specific password
A one-purpose password you create on Apple's website, so your real Apple password is never typed here.
Profile
A separate set of saved data and looks. Not a login.
Approval
Your yes to one kind of action, remembered for next time.
Workspace
The Live Desktop folder itself, the only place the assistant can read or write files.
